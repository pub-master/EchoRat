## 🧩 Overview

EchoRat includes:

### 📡 Backend Server (Node.js)
- Handles encrypted communication between clients and admin dashboard
- Dispatches commands and receives telemetry data
- Lightweight and scalable

### 🖥 Admin Dashboard (React + Next.js)
- Intuitive control panel for managing devices
- Real-time map, file system viewer, keylogger interface, and more
- Responsive design, multi-client support

### 📱 Android Client (Kotlin + Jetpack Compose)
- Stealth background operation with no launcher icon
- Auto-start on boot, auto-permission requests
- Features include:
  - Live camera (front/rear)
  - Live microphone stream
  - Keylogger and screen capture
  - GPS tracking
  - SMS, contacts, notifications access
  - File browser
  - Admin-level actions (lock, wipe, etc.)
